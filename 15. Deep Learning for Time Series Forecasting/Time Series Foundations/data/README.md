# Data

`synthetic_hourly_demand.csv` is a reproducible synthetic dataset created for this portfolio section.

It contains:

- `timestamp`
- `demand`
- `temperature`
- `humidity`

The demand series includes a small trend, daily seasonality, weekly seasonality, random noise, and several deliberately missing measurements for preprocessing demonstrations.

The synthetic dataset is used so the notebooks can clearly connect known structure to trend, seasonality, lag, autocorrelation, windowing, leakage, and forecasting evaluation.
