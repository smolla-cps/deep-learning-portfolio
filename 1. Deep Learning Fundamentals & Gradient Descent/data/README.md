# Data

`grades.xlsx` is used by `01_gradient_descent_and_backpropagation.ipynb`.

MNIST, Fashion-MNIST, CIFAR-10, and LFW are loaded through TensorFlow/Keras or scikit-learn in
the corresponding notebooks.

The CelebA experiments reference the image archive and attribute files used by the original
workflow. Those external CelebA files are not included in this repository package.
